### Overview

Context is expensive. Measure its value.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      Q-SCORE CONTEXTUEL                                  │
├─────────────────────────────────────────────────────────────────────────┤

│   └────────┬────────┘                                                   │
│            │                                                            │
│   ┌─────────────────┐                                                   │
│   │    C-SCORE      │  Context Token Value                              │
│   │                 │  C = 100 × ⁶√(R^φ² × F^φ × D^φ × A^φ × S × U)     │
│   └────────┬────────┘                                                   │
│            │                                                            │
│   ┌─────────────────┐                                                   │
│   │    N-SCORE      │  Knowledge Node Quality                           │

│   └─────────────────┘                                                   │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### O-Score (Operator Efficiency)

```javascript
O = 100 × (1 - F) × P × T

Where:
  F = Fatigue factor (0-1)
  P = Productivity (0-1)
  T = Time efficiency (0-1)

Fatigue Signals (φ-weighted):
  - Repetition rate:      × φ²
  - Error frequency:      × φ
  - Response latency:     × 1.0
  - Context switches:     × φ⁻¹
```

### C-Score (Context Token Value)

```javascript
C = 100 × ⁶√(R^φ² × F^φ × D^φ × A^φ × S × U)

Where:
  R = Relevance to current task
  F = Freshness (time decay)
  D = Dependency (how much relies on it)
  A = Actionability
  S = Specificity
  U = Uniqueness
```

**Context Segment Taxonomy:**

| Category | C-Score | Action |
|----------|---------|--------|
| CRITICAL | ≥ 76.4% | KEEP at all costs |
| IMPORTANT | ≥ 61.8% | KEEP |
| EPHEMERAL | ≥ 38.2% | COMPRESS |
| NOISE | < 38.2% | DISCARD |

### N-Score (Knowledge Node Quality)

Like K-Score but for knowledge nodes.

```javascript
N = 100 × ∛(U × C × T)

Where:
  U = Utilization (access frequency)
  C = Connections (to other knowledge)
  T = Trust (verification status)

Actions based on N-Score:
  N < 38.2%  → BURN candidate
  N < 61.8%  → TRANSFORM candidate
  N ≥ 61.8%  → KEEP
```
