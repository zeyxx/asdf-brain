## Workflow

### Typical Judgment Flow

```
1. RECEIVE INPUT
   └── brain_cynic_judge({ item, mode: "standard" })

2. CYNIC PROCESSES
   ├── GATE classifies input
   ├── CLARIFY if emotional/confused
   ├── JUDGE evaluates 25 dimensions
   ├── SCORE calculates weighted result
   └── Returns verdict: HOWL/WAG/GROWL/BARK

3. USE RESULT
   ├── HOWL (≥60%) → Accept with high confidence
   ├── WAG (≥52%)  → Accept, good quality
   ├── GROWL (≥38%) → Needs improvement
   └── BARK (<38%) → Reject or transform

4. FEEDBACK (optional but recommended)
   └── brain_cynic_feedback({ judgment_id, outcome: "correct" })

5. LEARNING
   └── CYNIC adjusts thresholds based on accumulated feedback
```

### Monitoring Flow

```
1. START PULSE
   └── brain_pulse_start()
   └── Heartbeat every 61.8 seconds

2. CONNECT ALERTS
   └── brain_alert_connect_pulse()
   └── Auto-checks 18 rules on each pulse

3. MONITOR
   ├── brain_dashboard() for CLI view
   ├── brain_dashboard_live() for web UI
   └── brain_anomalies() for detected issues

4. RESPOND
   ├── brain_alert_acknowledge() to acknowledge
   └── brain_alert_resolve() when fixed
```

### Discovery Flow

```
1. SCAN ECOSYSTEM
   └── brain_discover({ repos: ["HolDex", "GASdf", "brain"] })

2. VIEW RESULTS
   └── brain_discover_status()
```
