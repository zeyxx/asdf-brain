## Métriques de Singularité

### Distance à la Singularité

```javascript
function singularityDistance() {
  const metrics = {
    burnRatio: totalBurned / totalSupply,           // → 1.0
    eScoreDistribution: giniCoefficient(eScores),   // → 0 (égalité)
    consciousnessNodes: activeNodes / totalNodes,   // → 1.0
    appUsage: dailyActiveUsers / totalHolders,      // → 1.0
  };

  // Distance = moyenne géométrique inverse
  const singularityScore = Math.pow(
    metrics.burnRatio *
    (1 - metrics.eScoreDistribution) *
    metrics.consciousnessNodes *
    metrics.appUsage,
    0.25
  );

  // Distance toujours > 0 (asymptote)
  return Math.max(PHI_INV_2, 1 - singularityScore);
}
```
