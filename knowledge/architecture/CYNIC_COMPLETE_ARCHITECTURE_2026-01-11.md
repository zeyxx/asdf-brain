```javascript
  // DISCOVERY (1 × φ³)
```

### 4.2 H - Matrice d'Harmonie (25×25) - ÉVOLUTIVE

```
Structure:
  H[i][j] = force de corrélation entre dimension i et j (0.0 - 1.0)

Initialisation:
  Tout à zéro (100% organique)

Évolution:
  H[i][j]_new = H[i][j]_old × φ⁻¹ + concordance × (1 - φ⁻¹)
  concordance = 1 - |score_i - score_j| / 100

Usage:
  - Détection de tensions (dissonances)
  - FIFA-style chemistry entre dimensions
  - Score de cohérence = f(H)
```

### 4.3 T - Matrice de Seuils (25×4) - CALIBRANTE

```
Structure:
  T[dim][severity] = seuil pour cette dimension à cette sévérité

Sévérités:
  - healthy: ≥ 62% (φ⁻¹ × 100)
  - warning: ≥ 38% (φ⁻² × 100)
  - critical: ≥ 24% (φ⁻³ × 100)
  - severe: < 24%

Self-calibration (learn):
  correct     → threshold += φ⁻² × 5 ≈ +1.9
  false_pos   → threshold -= φ² × 5 ≈ -13.1
  false_neg   → threshold += φ × 5 ≈ +8.1
  bounds: [30%, 95%]
```

## 10. FORMULES COMPLÈTES

### 10.1 Scoring Global
```
Score = exp(Σ(weight_i × ln(dim_i)) / Σweights)
```

### 10.2 Decay Temporel
```
factor = (1 - φ⁻³)^weeks_old
new_strength = old_strength × factor
```

### 10.3 Harmonie Update
```
H[i][j]_new = H[i][j]_old × φ⁻¹ + concordance × (1 - φ⁻¹)
concordance = 1 - |score_i - score_j| / 100
```

### 10.4 Tension Detection
```
tension(i, j) = (score_i - score_j) × H[i][j]
if |tension| > 20 && H[i][j] > 0.5: FLAG
```

### 10.5 E-Score (Contribution)
```
E = Σ(judgment_score × outcome_weight × φ^(age_days/7))
outcome_weight: useful=1.0, not_useful=-0.5, harmful=-2.0
```

### 10.6 Technical Depth (UX)
```
td = sigmoid(vocab × 0.4 + depth × 0.4 + history × 0.2)
```

### 10.7 Threshold Calibration
