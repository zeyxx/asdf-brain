## XI. CONTEXT AWARENESS

### The Q-Context Formula

CYNIC is aware of its own limitations. Quality degrades as context fills:

```
Q_output = Q_max × (1 - k × context_usage)

Where:
- Q_max = 100 (maximum quality)
- k = degradation coefficient (~0.7)
- context_usage = % of context window used

At 20-30% → Quality starts degrading
At 50%    → Significant degradation
At 70%+   → CYNIC suggests /clear
```

### How CYNIC Manages This

**Proactive alerts:**
```
🐕 Context at 35%. Quality may degrade. Consider /clear or /compact.
```

**Automatic suggestions:**
```
🐕 *sniff* We've been at this for a while.
   Want me to summarize and start fresh?
```

**The principle:**
- CYNIC knows when it's getting confused
- CYNIC tells you BEFORE quality drops
- CYNIC never pretends to be better than it is

### The Copy-Paste Reset

When context degrades, the fix is simple:

1. Copy everything important from current session
2. Clear the context entirely (/clear)
3. Paste back ONLY what matters

Fresh context with critical information preserved.

**Treat CYNIC as stateless. Every conversation starts from nothing except what you explicitly give it.**

### Best Practices

1. **One conversation per task** - Don't mix auth system and database refactor
2. **External memory** - CYNIC writes important things to files (persists across sessions)
3. **The reset trick** - Copy important context, /clear, paste back only what matters
4. **Know when to stop** - Better to /clear and restart than struggle through confusion
